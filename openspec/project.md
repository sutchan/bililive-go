# 项目上下文

## 目的
bililive-go 是一个多平台直播录制工具，支持对多个主流直播平台进行直播流监控和录制，提供 Web 界面进行管理。

## 技术栈
- Go 语言（后端核心）
- React + TypeScript（Web 界面）
- FFmpeg（视频处理）
- Docker（部署支持）

## 项目约定

### 代码风格
- Go 代码遵循 Go 官方代码风格，使用 `golangci-lint` 进行代码检查
- TypeScript 代码使用 ESLint 和 Prettier 进行格式化
- 命名规范：使用驼峰命名法，包名使用小写字母，避免下划线

### 架构模式
- 模块化设计，各直播平台实现独立封装
- 事件驱动架构，使用事件总线进行组件间通信
- 分层架构：API 层、业务逻辑层、数据访问层

### 测试策略
- 单元测试覆盖率不低于 80%
- 集成测试覆盖核心功能流程
- 使用 Mock 对象模拟外部依赖

### Git 工作流
- main 为主分支，用于生产发布
- dev 为开发分支，用于集成新功能
- 功能分支命名格式：feature/功能名
- 修复分支命名格式：fix/问题描述
- 提交消息使用语义化格式：<类型>: <描述>

## 领域上下文
- 直播平台：指提供直播服务的网站或应用，如 Bilibili、抖音、虎牙等
- 直播间：直播平台上的具体直播房间，每个房间有唯一标识符
- 直播流：直播间实时传输的音视频数据
- 录制器：负责捕获和保存直播流的组件
- 监听器：负责监控直播间状态变化的组件

## 重要约束
- 需支持多种直播平台的不同协议
- 需处理直播流不稳定的情况，如断流重连
- 需支持大规模直播间监控（数百个直播间）
- 需考虑存储容量和文件管理

## 外部依赖
- FFmpeg：用于处理音视频流
- 各直播平台的 API：用于获取直播间信息和直播流地址
- Docker：用于容器化部署
